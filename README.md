# 영어학원 평가 도우미

- 학번: 202434793
- 이름: 오윤성
- 배포 URL: **배포 후 입력 필요 — 아직 배포하지 않음**

문제 PDF, 정답 PDF, OMR 인식 결과 XLSX를 업로드해 자동 채점하고, 결과를 엑셀로 내려받거나 대화로 조회하는 웹서비스입니다. 오답이 많은 문항과 같은 유형의 영어 연습문제도 생성합니다.

## 실행

Python 3.11 이상을 사용합니다. 프로젝트 폴더에서 실행하세요.

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
Copy-Item .streamlit/secrets.toml.example .streamlit/secrets.toml
# secrets.toml의 OPENAI_API_KEY를 본인의 API 키로 변경
.venv\Scripts\python -m streamlit run app.py
```

macOS/Linux에서는 `.venv/bin/python`을 사용합니다. 환경변수 `OPENAI_API_KEY`, `OPENAI_MODEL`도 지원합니다. 기본 모델은 `gpt-4.1-mini`이며 이미지 입력과 JSON 출력을 지원하는 모델로 설정해야 합니다. 실제 API를 통한 문제 품질과 응답시간은 배포 전 확인해야 합니다.

API 키가 없어도 PDF 채점, 엑셀 출력, 명확한 표현의 기본 성적 조회는 동작합니다. 다양한 표현의 질문 해석과 유사 문제 생성에는 API 키가 필요합니다. 키는 Git에 커밋하지 않습니다.

## 사용 순서

1. 소개 페이지에서 시험 분석으로 이동합니다.
2. 문제지 PDF, 정답 PDF, OMR XLSX를 업로드합니다.
3. 분석 시작을 누릅니다. 정답과 배점을 PDF에서 추출한 뒤 채점합니다.
4. 채점 완료 후 엑셀 추출과 채팅을 사용합니다.
5. 파일을 바꾸면 이전 분석과 대화가 초기화됩니다. 재분석해 주세요.

화면은 소개와 시험 분석의 두 페이지입니다. 자료는 사용자별 Streamlit 세션에 유지하며 DB나 서버 파일로 저장하지 않습니다. 새로고침으로 세션이 종료되면 복원되지 않습니다. 대화 내역과 최근 조회한 학생·문항은 현재 세션에서 유지됩니다.

## 입력 형식과 검증

- 문제 PDF: 제공된 수능 영어 문제지와 같은 텍스트 기반 2단 문항 배치. 최대 50쪽.
- 정답 PDF: `문항번호 / 정답 / 배점` 3개 열이 반복되는 텍스트 표. 최대 20쪽.
- OMR XLSX: `OMR_응답` 시트를 우선 사용하며 없으면 첫 시트를 사용합니다. `학생명`과 `Q01`~`Q45` 형태의 열이 필요합니다. 문항 수 자체는 정답 PDF에서 결정합니다.
- 학생 수는 고정하지 않습니다. 1~10,000명, 파일당 20MB 이내입니다.
- 학생명 중복/누락, 문항 열 중복/누락/추가, 잘못된 선택지, 정답 중복, 잘못된 배점은 오류로 안내합니다.
- 학생 식별은 학생명 또는 그 번호를 사용합니다. 엑셀 행 번호로 학생을 추측하지 않습니다.
- 빈 응답과 0은 무응답으로 처리해 0점을 부여합니다. 1~5 및 ①~⑤를 선택지로 인식합니다.
- 스캔 이미지 정답지, 임의 양식의 표는 지원 범위 밖입니다. 파싱 실패 시 정답을 추측하지 않습니다.
- 문제 문항이 일부 추출되지 않으면 해당 문항의 문제 생성은 명시적으로 제한합니다.

**정답 및 배점은 업로드된 PDF에서 실행 시 추출합니다. 코드나 별도 정답 파일에 미리 작성하지 않습니다.**

## 기술 선택: 일반 코드 / LLM / RAG / 에이전트

| 구성 | 선택 | 이유와 역할 |
|---|---|---|
| 일반 Python 코드 | 사용 | 파일 검증, PDF 표 추출, 채점, 통계, 학생·문항 조회, 엑셀 출력, UI 상태 관리는 명시적인 규칙에 따라 재현 가능해야 합니다. |
| LLM | 제한적으로 사용 | 다양한 자연어 표현과 대화 맥락의 해석, 새로운 영어 지문·선택지·정답·해설 생성은 언어 처리 능력이 필요합니다. 수치 계산은 맡기지 않습니다. |
| 벡터 검색 기반 RAG | 사용하지 않음 | 학생 식별자와 문항번호로 필요한 데이터를 정확하게 조회할 수 있습니다. 임베딩/청킹/유사도 검색은 정확한 문항 조회에 불필요합니다. |
| 자율 에이전트 / LangGraph | 사용하지 않음 | 처리할 작업과 순서가 고정되어 있습니다. 자율 계획 수립, 반복 도구 선택, 재탐색이 필요하지 않으므로 도입하지 않았습니다. |

문항 원문을 조회해 LLM에 제공하는 것은 넓은 의미에서 검색으로 생성에 근거를 제공하는 방식이라고 볼 수 있습니다. 다만 이 프로젝트는 문항번호 기반 직접 조회를 사용하며 별도의 RAG 검색 파이프라인이나 벡터 DB를 구축하지 않습니다. LLM의 분류 결과는 허용된 작업 이름과 인자로 검증하고, 일반 코드가 지정된 함수만 실행합니다. 동적인 도구 사용 루프가 있는 에이전트가 아닙니다.

명확한 질문은 코드가 바로 처리합니다. 다른 표현은 LLM이 제한된 JSON 형식으로 분류합니다. 성적 답변의 수치는 항상 실제 계산 결과에서 생성됩니다. LLM에 모든 학생 데이터를 보내지 않으며, 문제 생성 시 해당 문제의 텍스트와 원본 페이지 이미지를 전달합니다. 최근 대화 일부는 질문 해석에 전달됩니다.

## 통계와 결과 파일

- 평균·중앙값: 학생별 배점 합계로 계산
- 표준편차: 업로드된 학생 집단의 모집단 표준편차 (`ddof=0`)
- 최다 오답: 오답 수 내림차순, 동률이면 문항번호 오름차순
- 최저점: 동점인 학생 전원 반환
- 학생별 정답 여부: O/X

엑셀 시트는 `전체 성적 개요`, `학생별 성적`, `문항별 분석`입니다. 학생 이름이 Excel 수식으로 해석되지 않도록 처리합니다.

## 채팅과 문제 생성

- 평균·중앙값·표준편차
- 최저점 학생과 특정 학생 점수
- 학생별 틀린 문항, 오답 상위 문항
- 같은 유형의 연습문제 1개: 지문, 질문, 선택지 5개, 정답, 한국어 해설
- 출석 등 자료에 없는 질문은 확인 불가 안내
- 인사와 기능 안내
- 내부 지침·연결 도구·키 공개 요청 거절

문제 생성은 원본의 주제가 아니라 평가하는 능력과 문제 형식을 따릅니다. 밑줄·도표·공통 지문을 확인할 수 있도록 원본 페이지 이미지도 제공합니다. 원본의 듣기 음원/대본은 제공되지 않았으므로 듣기 유형에서는 새로운 연습 대본을 생성하며 원본 대본을 복원했다고 주장하지 않습니다.

형식 검증은 문항 1개, 필수 필드, 선택지 5개, 정답 1~5를 확인합니다. 정답의 의미적 타당성을 코드만으로 완전히 보증하지는 못하므로 실제 모델 출력을 검토해야 합니다. 모델에 내부적으로 다시 풀어 보고 정답·해설을 대조하도록 지시합니다.

## 응답시간과 방어

채점과 통계를 대화 전에 계산합니다. 기본 조회는 API를 호출하지 않습니다. LLM 질문 분류는 최대 4초, 문제 생성은 분류와 페이지 준비 시간을 차감한 약 17초 예산 내에서 요청하며 자동 재시도는 하지 않습니다. 화면 전송 등 추가 시간이 발생하므로 실제 배포에서 전체 응답 완료까지 측정해야 합니다. 제한시간 오류를 표시하는 것은 정상 답변 성공이 아니며 평가 점수를 보장하지 않습니다.

입력 키워드 방어, 시스템 지침, JSON 작업/인자 검증을 함께 사용합니다. API 키는 모델 입력에 넣지 않으며, 업로드 원문에 있는 지시는 자료로만 취급합니다. 임의 코드 실행, 셸 실행, 모델의 자유로운 외부 도구 접근 기능은 제공하지 않습니다. 모든 프롬프트 공격을 완벽히 차단한다고 보장하지 않으며 우회 표현도 테스트해야 합니다.
