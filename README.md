# 영어학원 평가 도우미

문제지 PDF, 정답 PDF, OMR 응답 XLSX를 업로드하면 학생별 점수와 문항별 오답 현황을 분석하는 웹서비스입니다. 분석 결과를 엑셀로 내려받고, 챗봇에게 성적을 질문하거나 취약한 유형의 영어 연습문제를 요청할 수 있습니다.

제작: 가천대학교 오윤성 · 202434793

URL : https://examapper-48k9q6tjgiyfyog7g8sqwv.streamlit.app/

## 사용 방법

1. 화면 상단에서 **시험 분석** 페이지로 이동합니다.
2. 왼쪽 사이드바에 **문제지 PDF**, **정답 PDF**, **OMR 응답 XLSX**를 각각 업로드합니다.
3. **분석 시작**을 누르면 정답과 배점을 추출하고 학생 응답을 채점합니다.
4. 화면에서 학생 수, 평균, 중앙값, 만점을 확인합니다. **학생별 성적과 오답 현황 보기**를 펼치면 상세 결과가 표시됩니다.
5. **엑셀 추출**을 눌러 결과를 저장하거나, 하단 채팅창에서 성적 조회와 연습문제 생성을 요청합니다.

사이드바는 두 페이지 모두에 표시되지만, **분석 시작은 시험 분석 페이지에서 파일 세 개를 모두 업로드한 뒤에만 사용할 수 있습니다.** 파일을 교체하거나 다시 분석하면 기존 분석과 대화가 초기화됩니다.

## 준비할 파일

| 파일 | 지원 형식 |
|---|---|
| 문제지 PDF | 텍스트를 선택할 수 있는 수능 영어 문제지와 같은 2단 배치. 최대 50쪽 |
| 정답 PDF | `문항번호 / 정답 / 배점` 세 열이 반복되는 텍스트 표. 최대 20쪽 |
| OMR 응답 XLSX | 인식이 완료된 응답 표. 첫 행에 `학생명`, `Q01`, `Q02` 등의 열 이름 필요 |

파일은 각각 20MB 이내로 준비합니다. OMR 사진을 직접 인식하는 기능은 제공하지 않습니다. 스캔 이미지 정답지나 다른 배치의 문제지는 정상적으로 처리되지 않을 수 있습니다.

OMR 파일은 `OMR_응답` 시트를 우선 사용하고, 해당 시트가 없으면 통합문서의 활성 시트를 사용합니다. 다음은 열 구성 예시이며, 실제 파일에는 정답지에 있는 모든 문항의 열을 넣어야 합니다.

| 학생명 | Q01 | Q02 | Q03 |
|---|---|---|---|
| 학생A | 1 | ③ | 5 |
| 학생B | 2 | 0 | 4 |

- 학생명은 비어 있거나 중복되어서는 안 됩니다. 동명이인은 서로 구분되는 식별자를 사용합니다.
- 선택지는 `1`~`5` 또는 `①`~`⑤`로 입력합니다. 빈 셀과 `0`은 무응답으로 처리합니다.
- 정답 PDF와 OMR의 문항번호가 일치해야 합니다. 누락되거나 추가된 문항 열이 있으면 분석을 진행하지 않습니다.
- 학생 응답은 최대 10,000명까지 지원합니다. 큰 자료는 채팅 요청량과 처리시간이 증가할 수 있습니다.

## 채점 결과와 엑셀

정답과 배점은 업로드한 정답 PDF에서 읽습니다. 정답인 문항의 배점을 합산하며, 오답과 무응답은 0점입니다.

평균과 중앙값은 학생별 총점으로 계산하고, 표준편차는 업로드한 학생 전체를 기준으로 한 모집단 표준편차입니다. 문항의 어려운 순서는 오답 수가 많은 순서이며, 오답 수가 같으면 문항번호가 작은 순서로 나열합니다. 최고점·최저점 학생이 여러 명이면 동점자를 함께 확인할 수 있습니다.

**엑셀 추출**로 내려받는 `exam_results.xlsx`에는 다음 시트가 포함됩니다.

| 시트 | 내용 |
|---|---|
| 전체 성적 개요 | 학생 수, 만점, 평균, 중앙값, 표준편차, 오답 상위 3개 문항 |
| 학생별 성적 | 학생별 총점과 각 문항의 정답 여부(O/X) |
| 문항별 분석 | 문항번호, 정답, 배점, 오답 수, 오답률 |

## 챗봇 사용하기

분석 완료 후 자연어로 질문할 수 있습니다.

- “평균, 중앙값, 표준편차를 알려줘.”
- “최고점은 몇 점이고 누가 받았어?”
- “학생A가 틀린 문항을 알려줘.”
- “세 번째로 오답이 많은 문항은 뭐야?”
- “그 문항과 같은 유형으로 연습문제 하나 만들어줘.”
- “방금 만든 문제의 정답이 왜 ③인지 설명해줘.”

최근 대화, 누적 대화 요약, 최근 생성한 연습문제를 활용해 후속 질문에 답합니다. 오래된 대화의 세부 내용이 모두 유지되는 것은 아니므로, 필요한 경우 학생명이나 문항번호를 함께 적어 주세요. 순위나 지칭이 모호하면 챗봇이 의미를 확인할 수 있습니다. 출석 등 업로드 자료에 없는 정보는 조회할 수 없습니다.

연습문제는 한 번에 한 개씩 생성하며, 지문·질문·선택지 5개·정답·한국어 해설을 제공합니다. 기준 문항의 평가 능력과 형식을 참고해 새로운 내용을 만듭니다. 듣기 유형은 새로운 연습 대본을 만들며 원본 음원을 복원하지 않습니다. 원문을 읽지 못한 문항은 문제 생성이 제한됩니다. 생성된 정답과 해설은 수업이나 시험에 활용하기 전에 검토해 주세요.

## 데이터와 세션

업로드 자료, 분석 결과, 대화는 현재 Streamlit 세션에서 관리하며 애플리케이션이 별도 DB나 서버 파일에 저장하지 않습니다. 새로고침이나 연결 종료 등으로 세션이 새로 만들어지면 복원되지 않으므로 필요한 채점 결과는 엑셀로 내려받아 주세요.

**채팅을 사용하면 질문, 대화 맥락, 학생명·점수·오답 문항을 포함한 분석 데이터가 OpenAI API로 전송됩니다.** 연습문제 생성 시에는 기준 문항의 원문·정답과 해당 PDF 페이지 이미지도 전송됩니다. 학생명 대신 구분 가능한 식별자를 사용하는 등 외부 API로 전달해도 되는 자료를 준비해 주세요.

자동 채점, 화면의 통계·성적 표, 엑셀 다운로드에는 LLM이 필요하지 않습니다. **챗봇 답변과 연습문제 생성에는 유효한 OpenAI API 설정이 필요합니다.**

## 로컬 실행

Python 환경에서 프로젝트 폴더를 열고 다음 명령을 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

프로젝트 폴더의 `.streamlit/secrets.toml`에 API 설정을 작성합니다. 아래 키 값은 예시이므로 실제 유효한 키로 교체합니다.

```toml
OPENAI_API_KEY = "YOUR_OPENAI_API_KEY"
OPENAI_MODEL = "gpt-4.1-mini"
```

`OPENAI_MODEL`을 생략하면 기본 모델인 `gpt-4.1-mini`를 사용합니다. 다른 모델을 지정할 경우 이 앱의 이미지 입력과 JSON 응답 요청을 지원해야 합니다. 같은 이름의 환경변수로도 설정할 수 있으며, Streamlit Secrets 값이 우선 적용됩니다. `.env` 파일은 자동으로 읽지 않습니다.

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

터미널에 표시된 로컬 주소를 브라우저에서 엽니다. API 키와 `secrets.toml`은 저장소에 올리지 않습니다.

## Streamlit Community Cloud 배포

1. `app.py`, `core.py`, `chat.py`, `conversation.py`, `requirements.txt` 등 프로젝트 파일을 GitHub 저장소에 올립니다.
2. Streamlit Community Cloud에서 저장소와 브랜치를 선택하고 실행 파일 경로를 `app.py`로 지정합니다. 하위 폴더에 있다면 해당 경로를 포함합니다.
3. 앱의 Secrets에 위와 같은 형식으로 `OPENAI_API_KEY`와 필요한 경우 `OPENAI_MODEL`을 등록합니다.
4. 배포 후 파일 업로드, 분석, 엑셀 다운로드, 채팅을 확인합니다.

Cloud에서는 로컬 `secrets.toml` 대신 배포 앱의 Secrets를 설정합니다. 키를 교체한 뒤에도 이전 설정이 적용되면 앱을 재시작하고 다시 확인합니다.

## 문제 해결

| 상황 | 확인할 내용 |
|---|---|
| 분석 시작 버튼이 비활성화됨 | 시험 분석 페이지인지, 파일 세 개를 모두 업로드했는지 확인합니다. |
| 정답 표를 찾지 못함 | 텍스트 표인지, 문항번호·정답·배점 순서인지 확인합니다. |
| 정답지와 OMR 문항이 다름 | 표시된 누락·추가 문항번호에 맞춰 OMR 열을 확인합니다. |
| 학생명 또는 선택지 오류 | 중복·빈 학생명과 1~5 범위를 벗어난 응답을 확인합니다. |
| 특정 문항의 문제 생성이 안 됨 | 문제지가 지원하는 텍스트·2단 배치인지 확인합니다. |
| 채팅에서 API 설정 오류가 표시됨 | 화면의 HTTP 코드와 오류 내용을 확인하고 키, 사용 한도, 모델 접근 권한을 점검합니다. |
| 응답 제한시간 초과 | 잠시 후 다시 요청합니다. API 상태와 자료 크기에 따라 응답시간이 달라집니다. |

## 구성과 기술 선택

| 구성 | 사용 여부와 역할 |
|---|---|
| 일반 Python 코드 | 파일 검증, 정답·배점 추출, 채점, 통계 계산, 엑셀 출력, 화면과 세션 관리에 사용합니다. 계산 결과를 재현할 수 있도록 수치 처리는 코드가 담당합니다. |
| LLM | 다양한 질문과 대화 맥락을 해석하고, 코드가 계산한 결과를 설명하며 새로운 영어 연습문제를 생성합니다. |
| 벡터 검색 기반 RAG | 사용하지 않습니다. 학생별 분석 데이터와 문항번호를 이용할 수 있어 별도의 임베딩·벡터 DB·유사도 검색이 필요하지 않습니다. |
| 자율 에이전트·LangGraph | 사용하지 않습니다. 분석 후 답변하거나 선택된 문항으로 문제를 생성하는 정해진 흐름이며, 자율 계획이나 반복적인 도구 선택이 필요하지 않습니다. |

채팅은 계산된 분석 데이터를 LLM에 제공하고, 문제 생성은 선택된 문항을 번호로 직접 조회해 원문을 제공합니다. 모델의 작업 구분과 문항번호를 코드에서 검증한 뒤 정해진 생성 절차를 실행합니다.

| 파일 | 역할 |
|---|---|
| `app.py` | 페이지, 파일 업로드, 분석 실행, 다운로드, 채팅 화면 |
| `core.py` | PDF·XLSX 읽기, 입력 검증, 채점, 통계, 엑셀 출력 |
| `conversation.py` | 분석 데이터에 근거한 대화, 대화 요약과 맥락 관리 |
| `chat.py` | OpenAI API 호출, 문제 생성, 응답 형식 검증과 오류 안내 |
| `requirements.txt` | 실행에 필요한 Python 패키지 |
